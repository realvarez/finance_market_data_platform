# Kafka Topics

## Topic Definitions

| Topic | Purpose | Key | Partitions | Retention |
|-------|---------|-----|------------|-----------|
| `market.ticks` | Real-time tick events from Yahoo WebSocket | symbol | 3 | 7 days |
| `market.candles.raw` | Historical candles from Yahoo Finance API | symbol | 3 | 30 days |
| `market.candles.calculated` | OHLCV candles generated by Spark from ticks | symbol | 3 | 30 days |
| `market.candles.reconciled` | Validated/corrected candles after reconciliation | symbol | 3 | 90 days |
| `market.signals` | Trading signals from strategy engine | symbol | 1 | 30 days |
| `market.errors` | Malformed or rejected market events | — | 1 | 7 days |

## Producers and Consumers

| Topic | Producers | Consumers |
|-------|-----------|-----------|
| `market.ticks` | tick-ingestion service | Spark candle builder, MinIO sink |
| `market.candles.raw` | Airflow candle DAGs | Reconciliation, ClickHouse |
| `market.candles.calculated` | Spark candle builder | Reconciliation, ClickHouse |
| `market.candles.reconciled` | Reconciliation job | ClickHouse, MinIO, Feature engine |
| `market.signals` | Signal engine (future) | Risk engine, API |
| `market.errors` | All ingestion services | Monitoring |

## CLI Commands

### List topics

```bash
docker compose exec broker kafka-topics --list --bootstrap-server localhost:9092
```

### Describe a topic

```bash
docker compose exec broker kafka-topics \
  --describe --topic market.ticks --bootstrap-server localhost:9092
```

### Consume messages

```bash
docker compose exec broker kafka-console-consumer \
  --bootstrap-server localhost:9092 \
  --topic market.ticks \
  --from-beginning \
  --max-messages 5
```

### Produce a test message

```bash
echo '{"event_id":"test1","symbol":"TEST","timestamp":"2026-08-12T14:30:00Z","price":100.0,"source":"test"}' | \
  docker compose exec -T broker kafka-console-producer \
  --bootstrap-server localhost:9092 \
  --topic market.ticks
```

## Bootstrap Servers

| Context | Address |
|---------|---------|
| Host machine | `localhost:9092` |
| Docker network (internal) | `broker:29092` |

Services inside Docker Compose use `broker:29092`. Local development scripts use `localhost:9092`.
